# 🏦 BankApp - Production Setup Guide\n\n## 📋 Overview\n\nThis guide will help you set up and test the complete **BankApp** (Backend + Frontend) with OTP verification and UPI payment flow.\n\n---\n\n## 🚀 Quick Start (Local Testing)\n\n### Prerequisites\n1. **Java 17+** (Backend)\n2. **Node.js 18+** (Frontend)\n3. **MySQL 8.0+** (Database)\n4. **Redis 6.0+** (OTP caching)\n5. **Git**\n\n---\n\n## 📦 Step 1: Clone Repositories\n\n### Backend Repository\n```bash\ngit clone https://github.com/Rohit-garugu/BankApp-Backend.git\ncd BankApp-Backend\n```\n\n### Frontend Repository\n```bash\ngit clone https://github.com/Rohit-garugu/BankApp-frontend.git\ncd BankApp-frontend\n```\n\n---\n\n## 🗄️ Step 2: Database Setup (MySQL)\n\n### Create Database\n```sql\nCREATE DATABASE bank;\nUSE bank;\n```\n\n### Update Backend Configuration\nEdit: `src/main/resources/application.properties`\n\n```properties\nspring.application.name=bank_app\n\n# MySQL Configuration\nspring.datasource.url=jdbc:mysql://localhost:3306/bank\nspring.datasource.username=root\nspring.datasource.password=root\n\nspring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver\nspring.jpa.database-platform=org.hibernate.dialect.MySQLDialect\n\nspring.jpa.hibernate.ddl-auto=update\nspring.jpa.show-sql=true\n\n# Redis Configuration (for OTP)\nspring.redis.host=localhost\nspring.redis.port=6379\n```\n\n---\n\n## 🔴 Step 3: Redis Setup\n\n### Start Redis Server\n\n**Windows (using WSL or Docker):**\n```bash\ndocker run -d -p 6379:6379 redis:latest\n```\n\n**macOS:**\n```bash\nbrew install redis\nbrew services start redis\n```\n\n**Linux (Ubuntu/Debian):**\n```bash\nsudo apt-get install redis-server\nsudo systemctl start redis-server\n```\n\n### Verify Redis is Running\n```bash\nredis-cli ping\n# Should return: PONG\n```\n\n---\n\n## ⚙️ Step 4: Run Backend (Spring Boot)\n\n```bash\ncd BankApp-Backend\n\n# Build the project\nmvn clean install\n\n# Run the application\nmvn spring-boot:run\n```\n\n**Expected Output:**\n```\n...\nTomcat started on port(s): 8080 (http)\nStarted BankAppApplication in X.XXX seconds\n```\n\n### Backend API is now running at:\n```\nhttp://localhost:8080\n```\n\n---\n\n## 🎨 Step 5: Run Frontend (Angular)\n\n```bash\ncd BankApp-frontend\n\n# Install dependencies\nnpm install\n\n# Run the development server\nng serve --open\n```\n\n**Expected Output:**\n```\n✔ Compiled successfully.\n✔ Executing initialization hooks\n✔ Built successfully.\n\n✔ Initial chunk files | Initial total size | Cached size\n...\n\nApplication bundle generated successfully (X.XXX seconds).\n```\n\n### Frontend is now running at:\n```\nhttp://localhost:4200\n```\n\n---\n\n## 🧪 Step 6: Testing the Application\n\n### A. Create Test Account\n\n1. **Open Frontend:** http://localhost:4200\n2. **Click:** \"Accounts\" → \"Personal Banking\" → \"Sign up for Personal Banking\"\n3. **Fill Form:**\n   - Account Name: `Savings Account`\n   - Account Type: `Savings`\n   - Balance: `50000`\n   - Account Holder Name: `John Doe`\n   - Username: `johndoe`\n   - Password: `password123`\n   - Account Number: `1234567890`\n   - IFSC Code: `BANK0001`\n4. **Click:** \"Create Account\"\n\n### B. Login to Dashboard\n\n1. **Go to:** http://localhost:4200\n2. **Click:** \"Accounts\" → \"Personal Banking\" → \"Personal Banking Login\"\n3. **Enter:**\n   - Username: `johndoe`\n   - Password: `password123`\n4. **Click:** \"Sign In\"\n\n### Expected: You are now on the Savings Account Dashboard\n\n---\n\n## 💳 Step 7: Test UPI Payment Flow\n\n### On Savings Dashboard:\n\n1. **Click:** \"🔷 Send Money (UPI)\" Button\n2. **A Modal Opens with 2 Steps:**\n\n#### **Step 1: Verify Mobile Number**\n   - Enter Mobile Number: `9876543210` (or any number)\n   - Click: \"Send OTP\"\n   - Enter OTP: `123456` (default test OTP)\n   - Click: \"Verify OTP\"\n   - You'll see: \"✅ Mobile verified successfully\"\n\n#### **Step 2: Payment Details**\n   - From UPI ID: `johndoe@bankapp` (auto-filled)\n   - Available Balance: `₹ 50,000.00` (auto-filled)\n   - Receiver UPI ID: `receiver@bankapp`\n   - Amount: `1000`\n   - Remarks: `Test Payment`\n   - Click: \"Pay Now\"\n\n### Expected Result:\n   - ✅ Success Message: \"Payment successful! Transaction ID: TXN-123456\"\n   - Balance updates to: `₹ 49,000.00`\n   - Transaction appears in history\n\n---\n\n## 📡 Backend API Endpoints (For Manual Testing)\n\n### Authentication\n```\nPOST http://localhost:8080/api/accounts/login\nContent-Type: application/json\n\n{\n  \"username\": \"johndoe\",\n  \"password\": \"password123\"\n}\n```\n\n**Response:**\n```json\n{\n  \"id\": 1,\n  \"account_name\": \"Savings Account\",\n  \"account_type\": \"Savings\",\n  \"balance\": 50000,\n  \"account_holder_name\": \"John Doe\",\n  \"username\": \"johndoe\",\n  \"accountNumber\": \"1234567890\",\n  \"ifscCode\": \"BANK0001\"\n}\n```\n\n### Send OTP\n```\nPOST http://localhost:8080/api/accounts/send-mobile-otp?username=johndoe&mobileNumber=9876543210\n```\n\n**Response:**\n```json\n{\n  \"message\": \"OTP sent successfully\",\n  \"timestamp\": \"2026-10-08T10:00:00Z\"\n}\n```\n\n### Verify OTP\n```\nPOST http://localhost:8080/api/accounts/verify-mobile?username=johndoe&mobileNumber=9876543210&otp=123456\n```\n\n**Response:**\n```json\n{\n  \"message\": \"Mobile verified successfully\",\n  \"verified\": true\n}\n```\n\n### Initiate UPI Payment\n```\nPOST http://localhost:8080/api/payments/upi\nContent-Type: application/json\n\n{\n  \"fromUpiId\": \"johndoe@bankapp\",\n  \"toUpiId\": \"receiver@bankapp\",\n  \"amount\": 1000,\n  \"otp\": \"123456\",\n  \"remarks\": \"Test Payment\"\n}\n```\n\n**Response:**\n```json\n{\n  \"transactionId\": \"TXN-20261008-123456\",\n  \"status\": \"SUCCESS\",\n  \"fromUpiId\": \"johndoe@bankapp\",\n  \"toUpiId\": \"receiver@bankapp\",\n  \"amount\": 1000,\n  \"timestamp\": \"2026-10-08T10:05:00Z\"\n}\n```\n\n### Get Account Balance\n```\nGET http://localhost:8080/api/accounts/johndoe\n```\n\n**Response:**\n```json\n{\n  \"id\": 1,\n  \"account_name\": \"Savings Account\",\n  \"balance\": 49000,\n  \"username\": \"johndoe\"\n}\n```\n\n### Get Transaction History\n```\nGET http://localhost:8080/api/transactions/johndoe\n```\n\n**Response:**\n```json\n[\n  {\n    \"id\": 1,\n    \"username\": \"johndoe\",\n    \"type\": \"debit\",\n    \"amount\": 1000,\n    \"balance\": 49000,\n    \"description\": \"UPI Transfer to receiver@bankapp\",\n    \"date\": \"2026-10-08\"\n  }\n]\n```\n\n---\n\n## 🧩 Testing with Postman\n\n### Import Collection\n\n1. Download Postman: https://www.postman.com/downloads/\n2. Create a new collection: \"BankApp\"\n3. Add requests from the API endpoints above\n\n### Example Test Flow:\n1. **POST** Login → Get user data\n2. **POST** Send OTP → Get OTP confirmation\n3. **POST** Verify OTP → Get verification\n4. **POST** UPI Payment → Get transaction ID\n5. **GET** Balance → Verify deduction\n\n---\n\n## ⚠️ Troubleshooting\n\n### Backend won't start?\n```bash\n# Check if port 8080 is in use\nlsof -i :8080\n\n# Kill process on port 8080\nkill -9 <PID>\n\n# Restart backend\nmvn spring-boot:run\n```\n\n### Redis connection error?\n```bash\n# Verify Redis is running\nredis-cli ping\n\n# If not, start Redis\ndocker run -d -p 6379:6379 redis:latest\n```\n\n### MySQL connection error?\n```bash\n# Verify MySQL is running\nmysql -u root -p\n\n# Create database if missing\nCREATE DATABASE bank;\n```\n\n### Frontend won't compile?\n```bash\n# Clear node_modules and reinstall\nrm -rf node_modules package-lock.json\nnpm install\nng serve --open\n```\n\n---\n\n## 🔐 Production Security Checklist\n\n- [ ] Use environment variables for sensitive data (DB credentials, Twilio API keys)\n- [ ] Enable HTTPS/SSL certificates\n- [ ] Implement rate limiting on OTP endpoints\n- [ ] Hash passwords using BCrypt\n- [ ] Add JWT token authentication\n- [ ] Implement CORS properly (not `*`)\n- [ ] Add request validation and sanitization\n- [ ] Enable database encryption\n- [ ] Set up logging and monitoring\n- [ ] Regular security audits\n\n---\n\n## 📊 Performance Metrics\n\n| Component | Port | Status |\n|-----------|------|--------|\n| Frontend (Angular) | 4200 | http://localhost:4200 |\n| Backend (Spring Boot) | 8080 | http://localhost:8080 |\n| MySQL Database | 3306 | localhost:3306 |\n| Redis Cache | 6379 | localhost:6379 |\n\n---\n\n## 📞 Support\n\nFor issues or questions:\n1.
